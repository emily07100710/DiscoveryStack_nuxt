# ML 資料來源目錄 V1

狀態：受治理的來源政策與已本機實作的擷取契約，操作與外部門檻見 [學習閉環 Runtime](../LEARNING_CLOSED_LOOP_RUNTIME_V1.md)。這份目錄不代表任何真實來源已取得授權、已收集或已可訓練。

## 先確認三件事

1. **有權使用**：來源擁有人、合約或授權條款明確允許預定用途；公開可讀不等於可供模型改進。
2. **仍可使用**：伺服器每次擷取前重新確認擁有人、客戶、來源、授權期限、模型改進同意、撤回、刪除要求、保留期限、條款及個資審查狀態。
3. **用途說得清楚**：每筆資料保留來源類型、權利依據、同意收據版本與雜湊、時間、資料範圍、去識別與審查狀態。撤回後停止新增使用，並依資料保留與撤回程序處理已收集項目。

擷取器不接受瀏覽器傳來的同意布林值、網址或授權狀態。它只接受伺服器解析出的來源識別碼，再由伺服器讀取目前有效的授權資料。任何欄位缺漏、所有人或來源不符、到期、撤回、條款不允許訓練、個資審查未通過或保留已終止，都必須在 DNS 或 HTTP 網路請求前拒絕。

## 可評估的資料來源

| 來源 | 可用內容 | 必要條件與限制 |
| --- | --- | --- |
| 客戶自有或明確授權的網站 | 經同意的公開頁面結構，例如標題、標題層級、canonical、連結數量、文字長度區間及內容雜湊 | 客戶需有權授權這些內容，並明確同意模型改進；逐次查驗目前授權與撤回狀態。只走 HTTPS、同一個授權主機、GET 請求；先讀目前的 `robots.txt` 並遵守禁止規則。頁數、深度、回應大小、時間與請求速率均有上限。遇到登入、驗證、WAF 或拒絕頁面即停止；不登入、不重用 Cookie、不繞過限制。 |
| Google Search Console（GSC）及 Google Analytics 4（GA4） | 經授權連接器提供的彙總搜尋曝光、點擊、流量與網站互動指標 | 由帳戶擁有人明確授權讀取；儲存彙總或最小必要欄位並套用個資審查。GSC 指標描述 Google 搜尋結果表現；GA4 描述網站或 App 的流量與互動。兩者衡量面向不同，數字可能不完全相符；它們不是 AI 引用是否發生的證據。[Google 的 GSC 與 GA4 指標說明](https://developers.google.com/search/docs/monitor-debug/google-analytics-search-console) 也指出兩種資料來源的度量不同、數值不必然一致。 |
| 經核准的第一方業務結果 | 例如經客戶核准、去識別化的詢問、合格名單、預約或成交狀態 | 只使用業務負責人核准且必要的欄位；移除姓名、聯絡資訊、自由文字及可識別個人的內容。須保留事件定義、歸因期間、來源系統、核准人及時間。觀察到的結果不應直接歸因於單一內容或模型變更，必須標示衡量方法與不確定性。 |
| 人工覆核的消費者 AI 搜尋或回答介面引用 | 人工在指定消費者介面實際看到的回答與引用狀態 | 每筆紀錄需保存核對時間、產品與介面、查詢版本、語系／地區、登入或個人化條件、人工覆核結果及可追溯的內部證據參照。螢幕擷取或回答原文須先作個資與權利審查，原文不直接進入一般模型投影。供應商 API 回答、合成探測、搜尋到某個網址、網站爬取結果或模型推論都不能自動標成「已引用」。未能人工核實即維持 `unknown`。 |
| 經權利核查的授權或開放授權資料 | 授權範圍內的內容、詞彙、分類或結構化資料 | 逐項確認授權人確有權授權該內容，並核對訓練、商業使用、衍生作品、署名、相同方式分享、地域、期限及再散布限制。Creative Commons 授權條件各有差異，例如 NC 限制商業用途、ND 限制散布改作；不能只因頁面標示 CC 就視為適合任何模型用途。[Creative Commons 授權條件](https://creativecommons.org/share-your-work/use-remix/cc-licenses/)；程式碼授權的「開放原始碼」定義也不等同一般文字或影像內容授權。[OSI 授權說明](https://opensource.org/licenses) |

來源登錄時應記錄可供審查的權利依據，不應只填「公開資料」「網路資料」或「開放資料」。若條款含義不清、權利人不明、用途超出授權、資料混有第三方作品，或無法確認商業／模型使用權，狀態維持待審，不擷取、不納入訓練。

## AI 可見度證據與標籤

不同觀察代表不同事實，資料集不可混為一談：

- **頁面觀察**：某個網址在某次擷取時回傳的頁面結構。只描述被觀察到的網站內容。
- **搜尋成效**：GSC 等來源彙總的搜尋曝光、點擊與查詢指標。只描述該搜尋來源的表現。
- **AI 引用觀察**：人工在指定消費者 AI 介面、特定時間與查詢中確認的引用。沒有可查核證據時一律為 `unknown`。
- **模型預測**：模型對可見度或成效的估計。它是預測，不是觀察結果。
- **已驗證業務結果**：依核准定義與來源紀錄確認的第一方業務事件。除非有合適的實驗設計或因果分析，不等於內容變更造成的結果。

網站爬取、GSC／GA4 彙總數據、供應商 API 答案、搜尋結果候選、模型預測均不得單獨用來推定消費者 AI 介面已引用。證據不足、資料缺漏、介面無法重現或人工尚未覆核時，保留 `unknown`；不可把 `unknown` 改寫成「沒有引用」或負樣本。

## 不可採用的取得方式

- 不得規避服務條款、付費牆、登入、驗證碼、WAF、速率限制或存取控制；不得假冒使用者或重用客戶 Cookie／Session。
- 不得因頁面公開、搜尋引擎可見、存在 sitemap 或 robots 未禁止，就推論取得模型訓練授權。
- 不做無差別全網抓取，不接受任意網址，不追蹤未授權網域或跨主機重新導向。
- 不記錄原始頁面本文、完整網址、查詢字串、Cookie、Authorization 標頭、秘密或原始個資到訓練投影或一般日誌。
- 不把供應商回應或爬取候選直接自動升格為引用標籤、訓練標籤、公開內容或已驗證成果。

`robots.txt` 是網站提供自動爬取規則的標準機制；本產品的學習擷取器採取遵守目前規則的政策。規則不可取得或解析失敗時停止學習擷取，而非當作允許。[IETF RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html)。這項政策不改變既有 Site Evidence 診斷爬蟲「將 robots 結果記為診斷證據」的產品行為；兩種用途必須保持分開。

## V1 學習擷取輸出

目前學習擷取器只產生有限的結構特徵：標題／H1／canonical／meta robots 是否存在、文字長度區間、連結數量區間、頁面內容雜湊及正規化網址雜湊。頁面本文與文字欄位只在記憶體中解析，不寫入學習投影。所有輸出標籤預設為 `unknown`，並要求人工覆核。這些結構特徵只是擷取觀察，未經品質、隱私、權利與標籤審查，不構成可訓練資料。

擷取採固定上限：最多 20 頁、深度 2、每個回應最多 256 KiB、整次最多 30 秒、同一來源請求至少間隔 1 秒。這些限制是流量與資料最小化措施，不會取代有效授權、個資審查、權利確認、人工標籤審查或受控模型發布。

## 上線與訓練前檢查

- [ ] 來源綁定正確擁有人、客戶與來源，且伺服器端權限仍有效。
- [ ] 已記錄明確的模型改進同意、版本、收據雜湊、同意／到期時間及撤回方法。
- [ ] 權利依據、授權條款與允許用途已審核；資料內第三方內容亦涵蓋在權利範圍內。
- [ ] `robots.txt` 可用且允許；HTTPS、同主機、重導向與網路目的地均通過安全檢查。
- [ ] 個資、敏感資料、權利與去識別化審查通過；資料保留與刪除期限已設定。
- [ ] 去重、品質、來源譜系及人工審查完成；未知標籤仍維持未知。
- [ ] 模型使用另經資料集核准、訓練紀錄、評估、偏差／安全審查、擁有人核准及受控部署流程；不得自動上線。

## 目前驗證狀態

- 真實客戶網站擷取：**NOT RUN**
- 真實 GSC／GA4 連線與匯入：**NOT RUN**
- 真實 AI 消費者介面人工引用覆核：**NOT RUN**
- 真實資料集核准或模型訓練：**NOT RUN**；本機合成資料已用於實際 CPU 擬合／分區評估測試，不證明正式模型品質。
- 本機單元測試只使用模擬 DNS 與 HTTP 回應，不代表外部網路、資料庫、部署或正式模型驗收。
